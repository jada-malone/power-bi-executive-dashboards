## Overview
I cleaned and modeled raw data, then built interactive executive dashboards with KPI cards, dynamic filters and trend analyses that made recurring reporting self-service.

## The goal
Replace recurring, manual reporting with dashboards leaders can explore on their own: the key numbers at a glance, with filters and trends to dig deeper.

## Data
Raw business data that had to be cleaned and transformed before it could be reported on.

## Approach
1. **Clean and transform:** prepared the raw data with Python, Excel and SQL.
2. **Model:** shaped the cleaned data into a model ready for reporting.
3. **Build:** designed interactive dashboards in Power BI and Tableau.
4. **Make it self-service:** added dynamic filters so users can answer their own questions without a new report request.

## What the dashboards include
- **KPI cards** for the headline metrics
- **Dynamic filters** to slice the data
- **Trend analyses** to show change over time
